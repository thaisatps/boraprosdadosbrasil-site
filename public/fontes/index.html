Fontes: os 50 arquivos oficiais por trás de cada número

Baixados dos portais do TSE, Banco Central, IBGE, Tesouro, Fed (o banco central dos EUA), Planalto, Congresso e STF, sem mudança. Cada um tem uma impressão digital (SHA-256) para conferir.

Por que confiar

Por que dá para conferir

  1. Os arquivos vêm direto dos portais oficiais, sem tratamento.
  2. Cada arquivo tem uma impressão digital (SHA-256): se um único número mudar, a impressão muda.
  3. As contas estão descritas em “Como calculamos” de cada página.
  • TSE 7
  • Banco Central 6
  • IBGE 3
  • Tesouro (SICONFI) 15
  • Fed 1
  • Tesouro (RTN) 9
  • Leis, notas técnicas e STF 9
  • = 50 arquivos
O que é SHA-256 e como conferirFechar

A impressão digital (SHA-256) é um código calculado a partir de cada byte do arquivo: se um único número mudar, o código muda.

Como conferir a impressão digital: no computador, rode shasum -a 256 nome-do-arquivo (Mac/Linux) ou certutil -hashfile nome-do-arquivo SHA256 (Windows) e compare com o código da lista de SHA-256.

O que é isto

  • São as fontes primárias das três análises, os arquivos como os portais oficiais os entregam. Nenhum número foi reescrito aqui. Você não precisa baixar nada para usar o site: esta página é para quem quer conferir as contas.
  • Formatos: PDF = documento oficial na íntegra (planos de governo, boletins do Tesouro, notas técnicas) · ZIP = pacote como publicado (totalização de votos, base de candidaturas) · JSON/JSONL = resposta das APIs oficiais · XLSX = planilha oficial · HTM/HTML = página oficial salva como estava (leis no Planalto, notícia do STF), que o botão baixa em vez de abrir.
