Uso interno · fora do índice

Componentes de interface

Peças prontas para as páginas de análise, com números reais copiados das páginas e da matriz de vereditos. Cabeçalho, menu de seções, faixa de credibilidade, rodapé e barra inferior (no celular, depois de rolar) já estão nesta página como em todas as outras.

Arquivos: /assets/css/site.css (seção "FUNDAÇÃO UI"), /assets/css/share.css, /assets/js/ui.js, /assets/js/share.js, /assets/js/charts.js. Todos os componentes funcionam sem JS (o <details> é nativo); o JS acrescenta compartilhar, o ajuste dos gráficos ao abrir e a barra inferior.
